# 二氧化碳全景 3D 全流程互动实验室 · v2

本版器材已经搭好，学生无需选器材或自行组装。打开即可在完整3D实验台上点击高亮操作点，按步骤完成实验。

## 离线使用

下载 `downloads/chemistry-co2-panorama-v2.zip`，解压后用较新 Chrome / Edge 双击 **二氧化碳全景实验室.html**。下载后运行无需联网或安装Node.js，浏览器需要WebGL2。不要在压缩包或网盘预览器内运行。

## 七步完整流程

1. 点击发生器旁的“检查气密性”，观察液柱维持。点击“继续：装入大理石”，系统排出检查水、打开气路并取下瓶塞。
2. 点击台前大理石盘或高亮按钮加入固体；点击“复塞，进入加液”，系统复装密封。
3. 点击稀盐酸瓶，经长颈漏斗加入反应液，观察发生器气泡。
4. 点击检验烧杯加入新鲜石灰水，系统切换气路。观察由澄清变浑浊；模型时间会停在关键现象处。真实反应不会自行暂停。
5. 点击“转入收集”，系统将气路转入瓶口朝上的集气瓶，导管末端近瓶底；继续收集。
6. 点击瓶口操作点或“燃着木条放在瓶口”。若仍燃烧，继续观察后再测试；可对比“木条伸入瓶内”。规范验满后点击“继续：盖片与记录”。
7. 点击玻璃片，系统移开导管并盖口。写下石灰水与瓶口木条的两组证据，保存或导出CSV。

默认自动推进。讲课可选择“手动观察”，每次点“观察5秒（虚拟）”。可旋转、缩放、切换发生器/集气瓶/石灰水特写。侧栏提供与场景相同的按钮，方便键盘和小屏操作。

## 八类独立易错示范

漏斗未液封、瓶塞未塞紧、出气管浸液、收集管靠近瓶口、集气瓶倒置、过早验满、木条伸入瓶内、反应时夹闭出口。可查看现象、原因与规范操作对照，切回完整实验保留原进度。错误示范是可旋转观察的独立模型快照，非实际危险试验。

CO₂无色，彩色点和路径仅是可选辅助示意。反应计量受限；速率、分区气体分布与火焰阈值为定性教学近似，不能当成实测时间、浓度和压力。程序化器材仍为临时资产。

## 开发和验证

在整个仓库根目录执行：

```sh
npm ci
npm run dev:chemistry
# http://localhost:5174
npm run test:chemistry
npm run build:chemistry
npx playwright install chromium
node chemistry/scripts/check-panorama.mjs
python3 chemistry/scripts/package.py
```

Node.js 20.19+ 或22.12+。模型在 `model.ts`，预装装置、七步流程和错误对照在 `lesson.ts`，三维在 `Scene.tsx`，教学界面和记录在 `main.tsx`。原凸透镜实验保持独立。
