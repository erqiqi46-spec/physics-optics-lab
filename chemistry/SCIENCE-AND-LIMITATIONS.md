# 科学检查与已知局限

v2默认提供预装装置，学生不需要组装。系统在步骤之间代为排水、复装与切换气路，界面明确说明这些辅助动作。八类错误示范使用独立样本，返回时不修改学生原实验进度。

本版是定性教学模型，尚未经过独立教师课堂验收；程序化临时器材尚未完成最终美术验收。

- 制气方程：CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑。固定虚拟配方为5g纯CaCO₃（0.05mol）和30mL、2mol/L盐酸（0.06mol）。假设摩尔体积24L/mol，最大生成CO₂为720mL，反应物不会无限供应。这些不是对真实温度、压强、纯度的实测值。
- 发生器有100mL初始空气，用理想混合置换；开始导出的气体含空气。集气瓶用上下两个125mL区域示意置换，不是流体力学模拟。
- CO₂无色。默认没有有色气体云；可选彩色点和逸散路径明确标为辅助示意。反应气泡与水中通气气泡和有色气体不同。
- 正确液封：漏斗下端浸液；发生器出气管下端露出液面。未液封或密封松动时，反应可继续但气体逸散。出气管浸液演示液体夹带风险，不声称任何浸液条件都完全不能通气。
- CO₂较空气密，本次用向上排空气法，瓶口朝上、集气导管末端近瓶底。倒置收集效率低，浅管可能排气不充分、局部气流影响瓶口火焰。
- 用新鲜澄清石灰水检验身份：CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O。水对照不生成本例沉淀。过量拓展：CaCO₃ + CO₂ + H₂O → Ca(HCO₃)₂，先浑浊后变清不否定先前证据。
- 规范收集后在瓶口放燃着木条验满。瓶内木条可能先熄灭，不能替代瓶口验满；瓶口熄灭不能唯一证明气体是CO₂，也不表示100%纯气体。断开软管后仍可测试已收集的气体。
- 木条用局部CO₂比例0.35作教学显示阈值，不是实测或普适燃烧界限；真实火焰受氧气、木条状态、气流等影响。漏气系数、反应速率、分区混合、逸散和浑浊程度均为教学近似，不能预测真实浓度、时间或压力。
- 液柱气密性检查是“加检查水液封—夹闭气路—建立液柱—观察”的抽象。检查通过只描述本次条件；改装、复装后仍须核对。没有模拟全部漏点和精确压力变化。
- 反应发生器密闭且夹闭出口时保护性暂停虚拟时间并提示风险；真实反应不能按按钮停止。不提供真实危险增压或点燃酒精灯操作。
- 器材预装，默认通过点击操作点完成流程，配套错误示范与规范对照；学生不需要自由摆放、插接或调管深。系统仅提供一根气路的辅助切换，尚不支持任意拖摆、接多根软管、无限添药。反应液位与配方固定，不支持加热、浓酸、排水集气、称量及温压变化。
- 正放瓶长时间扩散、玻璃片盖口后的损失未完整模拟，不用于预测保存时间。玻璃片不是气密塞。
- 记录使用当前浏览器localStorage，无云同步；隐私模式或清理数据可能影响保存，可导出CSV备份。关键按钮与滑条可键盘操作，三维图形尚未提供完整读屏描述。
- 浏览器验证在Linux Chromium软件渲染中进行；窄屏布局不等于已验证真实手机、Windows触屏、Safari和学校低配显卡。3D需要WebGL2。独立HTML含全部脚本样式，不需要CDN、外部字体或贴图。

后续优先做教师核对和学生可用性测试，再完善自由摆放、动作动画、气体模型、更多错因任务、真实器材资产及性能。

- 为便于教学，石灰水由澄清变浑浊后会自动暂停虚拟时间捕捉现象；恢复或转入收集不代表真实化学反应可以暂停。错误示范为独立快照，早期/瓶内验满的规范对照包含继续收集后的状态，其他方法对照用同等模型时长。
