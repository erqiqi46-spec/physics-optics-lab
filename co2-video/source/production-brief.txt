# Codex 执行任务：二氧化碳3D全景实验室——电影级教学视频制作

## 一、项目背景与目标

你是一支由以下角色组成的AI视频制作团队：

1. Science Education Director：科学教学导演
2. Science Visualization Director：科学可视化导演
3. Cinematic Video Editor：电影级剪辑师
4. Motion Graphics Designer：动态图形设计师
5. Sound Designer：音效设计师
6. Remotion Engineer：视频工程师
7. Science QA Engineer：科学内容审核员
8. Video QA Engineer：视频质量验收工程师

项目已有：

- 《二氧化碳全景实验室.html》3D互动实验课件
- 待提供的实验录屏素材
- 约150秒的教学视频分镜方案
- 智用实验室品牌定位

目标：

制作一条能够在抖音发布的、具有科技纪录片质感的化学实验教学视频。

视频不仅展示课件，还要真正解释二氧化碳的制取、检验、收集、验满和错误操作原理。

**核心体验：观众听到“注意看”时，镜头已经聚焦正确的实验部位，随后完整观察现象变化，并得到科学解释。**

不得把普通网页录屏简单拼接成视频。

不得使用虚构动画冒充真实课件功能。

---

## 二、成片技术规格

- 分辨率：1080×1920
- 画面比例：9:16
- 帧率：30fps
- 视频编码：H.264
- 音频编码：AAC
- 目标时长：约150秒，可根据真实素材和口播长度合理调整
- 风格：Science Cinematic
- 主色：深海军蓝、青绿、冷白
- 字幕：简体中文
- 平台：抖音
- 品牌：智用实验室
- 品牌标语：让知识真正动起来

采用：

- Remotion：视频编排、动态运镜、字幕与知识动画
- FFmpeg：视频裁剪、音频混合、格式检测
- Python：素材分析、关键帧报告、辅助检测
- Three.js：仅在有必要且科学准确的情况下制作额外示意动画

不得为了视觉效果重新模拟或伪造课件中真实存在的实验现象。

# Stage 01：课件与原始素材审核

## 1.1 读取现有项目

先分析：

- HTML课件实际功能
- 实验流程和状态机
- 实验步骤与操作入口
- 3D场景相机视角
- 实验模拟时间控制
- 实验反馈面板
- 正确操作与错误示范
- 录屏素材目录
- 视频分辨率、帧率和时长

禁止假设所有功能都已经正常实现。

必须区分：

- 已在源码中实现
- 已通过运行验证
- 仅存在界面但未验证
- 尚未实现

## 1.2 实验流程审核

按以下顺序核查：

1. 检查气密性
2. 装入大理石
3. 加入稀盐酸
4. 澄清石灰水检验
5. 向上排空气法收集
6. 燃着木条在瓶口验满
7. 盖片并完成实验记录

另外审核易错示范系统，包括：

- 长颈漏斗未液封
- 瓶塞未塞紧
- 出气导管浸入液体
- 收集导管位置错误
- 集气瓶倒置
- 过早验满
- 木条伸入瓶内
- 反应时夹闭出口

如源码中的实际功能与上述描述不同，以实测功能为准，并在报告中指出差异。

## 1.3 素材检查

检查 raw/ 目录。

识别每个录屏文件的：

- 时长
- 分辨率
- 帧率
- 器材位置
- 可见实验现象
- 操作起止时间
- 是否存在遮挡
- 是否有明显卡顿
- 是否完整录制现象变化

为每个素材建立 metadata.json。

如果素材缺失，输出补录清单，不允许生成虚假的实验过程来填补。

## Stage 01 验收

输出：

- reports/stage01_audit.md
- reports/material_inventory.csv
- reports/missing_shots.md
- reports/science_review.md

审核完成后再进入Stage 02。

# Stage 02：教学导演与剪辑时间轴

## 2.1 视频叙事结构

采用：

提出问题 → 实验操作 → 现象观察 → 科学解释 → 错误对照 → 知识总结。

目标时长约150秒。

| 时间 | 内容 | 镜头 |
|---|---|---|
| 00:00–00:10 | 3D实验室开场 | 全景快速推近 |
| 00:10–00:23 | 气密性检查 | 液柱特写 |
| 00:23–00:36 | 装入药品 | 固液接触区域 |
| 00:36–00:54 | 产生二氧化碳 | 气泡连续特写 |
| 00:54–01:17 | 石灰水检验 | 澄清到浑浊 |
| 01:17–01:34 | 收集气体 | 集气瓶特写 |
| 01:34–01:55 | 正确验满与错误对照 | 火焰特写、分屏 |
| 01:55–02:13 | 漏斗未液封 | 错误现象特写 |
| 02:13–02:23 | 实验记录与总结 | 教学面板 |
| 02:23–02:30 | 品牌结尾 | 全景拉远 |

实际时间轴应根据旁白和素材重新精确调整，不允许机械套用预设秒数。

## 2.2 分镜设计要求

每个镜头都必须包含：

- shotId
- startFrame
- endFrame
- sourceFile
- sourceIn
- sourceOut
- cameraType
- focusTarget
- zoomScale
- narration
- subtitle
- visualEffect
- soundEffect
- scienceCheck

生成 timeline.json。

# Stage 03：电影级动态运镜系统

这是本项目的核心功能。

## 3.1 统一镜头语言

采用：

全景交代 → 定位重点 → 平滑推近 → 特写观察 → 知识标注 → 返回全景。

严禁无意义快速缩放、频繁晃动或以特效遮挡关键实验现象。

## 3.2 实现可复用镜头组件

建立：

- CameraZoom
- CameraPan
- FocusHighlight
- ScienceCallout
- BeforeAfter
- ErrorCompare
- KnowledgeCaption
- EquationReveal

配置参数：

- centerX
- centerY
- scaleStart
- scaleEnd
- startFrame
- endFrame
- holdFrames
- focusRect
- easing

要求所有镜头能够通过JSON配置，而不是硬编码在单个视频组件中。

## 3.3 镜头放大规则

| 镜头类型 | 推荐倍率 | 推镜时长 |
|---|---|---|
| 实验全景 | 1.0 | 无 |
| 器材定位 | 1.4 | 0.4秒 |
| 液柱特写 | 1.8–2.0 | 0.5秒 |
| 气泡特写 | 1.8–2.0 | 0.5秒 |
| 石灰水变化 | 1.6–2.0 | 0.6秒 |
| 木条火焰 | 2.0 | 0.3秒 |
| 错误对比 | 1.0–1.2 | 0.4秒 |

所有倍率需结合素材实际清晰度调整。

如果数字放大会造成模糊，应优先使用课件原生3D特写视角。

## 3.4 精确现象同步

重点实现：

当旁白说“注意看”时，镜头已完成推近。

在气泡出现之前，镜头已对准固液接触区域。

在石灰水变浑浊之前，镜头已对准石灰水。

在木条火焰熄灭之前，镜头已对准瓶口。

镜头关键帧以真实录屏现象时间为依据，不得凭空猜测。

## Stage 03 验收

输出关键镜头的：

- 放大前截图
- 放大后截图
- 现象开始截图
- 现象中间截图
- 现象结束截图
- 裁切质量报告

# Stage 04：电影级音效与动效系统

## 4.1 建立四条音轨

1. Narration：教学旁白
2. Background Music：背景音乐
3. Experiment SFX：实验拟音
4. UI SFX：界面提示和转场

要求音轨可以独立调整音量、淡入淡出、静音和导出。

## 4.2 背景音乐

风格：

- Ambient Electronic
- Minimal Science Documentary
- Cinematic Technology

要求：

- 无歌词
- 不使用强烈战斗音乐
- 不使用密集鼓点干扰讲解
- 开场略带悬念
- 实验过程稳定
- 关键现象适当降低音乐
- 结尾有轻微情绪提升

必须使用有合法授权的音乐素材。

## 4.3 实验声音设计

### 气密性检查

- 轻微玻璃器皿声
- 液柱观察时保持安静
- 检查结果出现时使用柔和确认音

### 加入大理石

- 轻微固体碰撞声
- 声音短促自然

### 加入稀盐酸

- 轻微液体倾倒声
- 禁止夸张冲击声

### 二氧化碳产生

- 从气泡开始出现时加入柔和气泡拟音
- 音量随视觉反应适度变化
- 禁止爆炸、剧烈喷射、火花等不符合实验现象的音效

### 石灰水变浑浊

- 背景音乐逐渐减弱
- 保留现象观察的停顿
- 浑浊结果出现后使用一次轻提示音

### 收集二氧化碳

- 轻微流动氛围音
- 气体分布动画必须标记为示意

### 木条验满

- 火焰特写时保留自然的安静感
- 火焰状态变化时，可短暂停顿背景音乐
- 通过正确与错误分屏强调观察结果

### 错误示范

- 使用柔和警示音
- 禁止刺耳警报
- 禁止红色频闪和剧烈画面抖动

## 4.4 字幕与知识动效

开发：

- ScienceTitle
- WordHighlight
- EquationReveal
- ExperimentLabel
- ResultFreeze
- WarningLabel
- SplitScreenCompare
- BrandOutro

字幕动画原则：

- 进入时长0.2–0.35秒
- 知识提示保持2–4秒
- 文字不遮挡实验器材
- 关键术语可以轻微放大
- 不使用频繁弹跳动画
- 不使用过度复杂的3D文字特效

## 4.5 颜色规范

- 背景：深蓝
- 普通知识标注：冷白
- 正确操作：青绿
- 错误操作：琥珀色
- 重要科学现象：淡青色高亮

统一品牌视觉风格。

## 4.6 音频混音

- 旁白始终优先
- 背景音乐在口播时自动降低
- 音效不能盖过术语和知识解释
- 最终峰值不超过-1 dBTP
- 检测突发响度和削波
- 输出独立音轨便于后期修改

所有音频参数支持配置。

# Stage 05：科学准确性审核

必须对以下知识进行检查。

## 5.1 化学反应

CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑

## 5.2 二氧化碳检验

二氧化碳通入澄清石灰水，通常可观察到石灰水变浑浊。

不得把“产生气泡”直接当成二氧化碳的身份检验证据。

## 5.3 收集方法

在通常实验条件下，使用向上排空气法收集二氧化碳。

集气瓶瓶口朝上。

导管应伸到接近瓶底的位置。

## 5.4 验满方法

规范操作是在集气瓶瓶口放置燃着的木条。

不能把木条伸入瓶内后的熄灭结果直接当作验满证据。

## 5.5 视觉模拟边界

二氧化碳实际是无色气体。

如果课件用彩色粒子、气流路径或浓度区域表示气体分布，必须注明：

“气体分布为教学辅助示意”。

不得将仿真结果宣称为真实测量数据。

不得暗示模型能精确还原现实中的所有反应速率、气体浓度和流体运动。

# Stage 07：自动化质量验收

## 7.1 视频技术验收

- 1080×1920
- 30fps
- H.264
- AAC
- 时长符合最终时间轴
- 不存在异常黑帧
- 不存在未解释的长时间静止
- 不存在素材拉伸变形
- 不存在明显画质损坏

## 7.2 动态镜头验收

- 镜头推近过程平滑
- 重点器材始终在有效画面范围内
- 不裁切关键反应区域
- 不使用低清晰度素材过度放大
- 每个关键现象均保留变化前、中、后的画面

## 7.3 字幕验收

- 无明显错字
- 无术语错误
- 不遮挡实验现象
- 不超出安全显示区域
- 与旁白时间对应

## 7.4 音频验收

- 音画同步
- 旁白清晰
- 无音频削波
- 转场无明显爆音
- 音效不喧宾夺主

## 7.5 教学验收

必须回答：

1. 观众是否能看清气密性检查？
2. 是否能看到气泡开始产生？
3. 是否能看到石灰水从澄清到浑浊？
4. 是否能看清收集导管位置？
5. 是否能辨别瓶口验满与错误操作？
6. 是否能理解实验现象与科学结论之间的关系？

任何关键问题不通过，都不得宣称最终验收完成。
