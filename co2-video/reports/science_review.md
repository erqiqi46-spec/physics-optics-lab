# 科学审核报告

审核对象：原v3程序化课件画面、159秒中文脚本、字幕、后期结构示意。源码SHA256见raw-complete-qa.json；实验模型未改动。

1. 气密性：按原课件液柱法，封住导管后加水、观察液柱维持。影片仅说“本次检查条件下未发现明显漏气”，不推断任意条件永久气密。液柱建立为原课件离散状态。
2. 加药：先大理石，复装密封，再经长颈漏斗加稀盐酸。CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑配平正确。不以气泡作为鉴别CO₂的充分证据。
3. 检验：原生石灰水澄清到白色浑浊真实录到；沉淀CaCO₃，CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O。说明过量CO₂可能使浑浊消失，但原片本段未演示消失，不声称已演示。
4. 收集：CO₂密度比空气大，用向上排空气法，瓶口向上、导管接近瓶底。CO₂可溶于水且部分反应，初中制取收集不优先选排水法。初排气含空气，不能直接说纯CO₂。
5. 验满：燃着木条放瓶口；仍燃烧则继续收集后再测试。原模型点击时离散刷新熄灭结果，影片明确分段，未包装成实时连续氧浓度燃烧模型。熄灭不等于100%纯度，也不是CO₂独有鉴别依据。
6. 错误对照：瓶内木条熄灭、同一模型时刻瓶口仍燃烧；证明伸入瓶内不能判断收集满。漏斗下端未液封会漏气，反应仍可发生，收集效果变差。两组是独立模型快照，不是同次实验瞬间修复。
7. 结束：移出导管、盖玻璃片；玻璃片不等于气密密封。课件记录分开写现象与结论。

气体本身无色，彩色粒子与泄漏线已标注为教学辅助示意。后期导管/液封结构图有“结构示意/非实测流场”标识。时间、浓度、反应速率均非真实测量。
